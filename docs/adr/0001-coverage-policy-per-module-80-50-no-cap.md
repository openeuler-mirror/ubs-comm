# 覆盖率政策:每模块 80/50 且不设上限,软强制

2026-08-24 定稿:ubsocket 的 UT 覆盖率目标改为**每个模块行 ≥80% / 分支 ≥50%,越高越好不设上限**;全局目标不单独设数字,靠各模块达成(及超额)兜底——个别模块覆盖率难增长时,由其他模块超额达成来保证全局水位。不设 CI 硬门槛:每轮 sprint 结束由协调人重跑 `make coverage` 更新数据源(覆盖率数据源文档是唯一记录数字的地方),评审时按模块目标逐文件核对;整体水位达到约 60% 时重新评估是否引入 CI 强制。此决策的背景是 2026-08-24 实测全局覆盖率仅 18.1% 行 / 10.9% 分支,而旧文档基线(2026-05-27 快照)已全面过期。

**Status**: accepted

**Considered Options**:
- 分阶段小目标(如"profiling 先拉到 40%")— 被拒:需要协调页反复改数字,且与"靠超额补偿难涨模块"的兜底逻辑冲突
- 现在就设 CI 硬门槛 — 被拒:以 18.1% 的起点设 80% 的门会当场全红,门槛变成摆设;留待水位 60% 时再议
